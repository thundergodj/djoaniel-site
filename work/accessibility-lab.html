01 · The audit, live

Not screens. Surfaces.

Auditing feature by feature would never have finished. So the unit of audit became the surface — the recurring construct that every feature is assembled from. Four carry their own criteria. The fifth carries everyone else's.

Every control on the bench is a decision a designer or developer actually makes. The sheet on the right is the inspection sheet rebuilt in this site's own system — same taxonomy, same status vocabulary, same shape as the one the team works from. It re-renders as you work.

02 · Inherited

Audited once. Carried forever.

The first version of this template made every feature test all ten criteria. It was correct and it was unusable — nobody was going to re-measure the focus ring on the forty-first form.

So the taxonomy grew a third status. Inherited means the criterion is satisfied by a governed platform component, was audited once against Web apps & web services, and is carried by every feature that consumes it. A feature audit only tests what the feature itself introduces.

Open the platform block on the sheet, then switch surfaces. The four blue rows are identical on Tables, Forms, Status indicators and Transactions — same criteria, same wording, same source. That repetition isn't laziness in the artifact. It's the mechanism: a single platform pass, then nothing to re-litigate. Which is why the sheet keeps them folded shut until you ask.

03 · This page

It passes its own audit.

Every control here is reachable and operable from the keyboard alone. Each slider is duplicated by a −/+ button, so no part of this page depends on a dragging movement — the same criterion the artifact marks inherited. The verdict panel is a live region, so it is announced rather than merely shown. Contrast ratios are computed with the WCAG relative-luminance formula, not estimated.

Claiming accessibility work without shipping an accessible artifact would be the tell.

04 · What I cannot show you

The instrument is mine. The readings are not.

How many defects the sheet surfaced, how fast they closed, how the platform scores today, what any of it cost — that is Avaloq's data. It is not mine to publish, and a portfolio that published it would be telling you something about my judgement rather than my work.

So the evidence here is the instrument itself, rebuilt and running. You can operate every control, break every criterion, and read the verdict it produces. If the method holds up under that, the numbers it produced elsewhere are a formality — and if it doesn't, no number I quoted would have saved it.

The same rule governs every case on this site: the artifact is the evidence, the client keeps the outcome.
